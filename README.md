## 项目简介

面向 AOI 门板外观检测的端到端链路：从数据资产沉淀、人工与模型协同标注，到模型训练与版本化发布，最终在产线侧完成自包含推理。

系统拆分为两个可独立部署的平台 —— **平台 A** 位于中心侧，负责「把数据变成模型」；**平台 B** 位于产线侧，负责「把模型变成判定」。两者通过模型仓库解耦，互不直接依赖。

---

## ✨ 能力说明

### 平台 A · 训练与标注（中心侧）

- **数据资产管理** —— 缺陷字典支持版本化快照与发布；数据集管理覆盖创建、版本管理与训练/验证划分；图片批量导入自带全局去重与异步处理，无需等待。
- **标注协同** —— 服务端按模板自动创建标注项目，接入即可开标；模型预标签按置信度分为高 / 中 / 低三桶（宁错不漏），低置信度强制人工复核，人工只处理真正需要的部分。
- **复审工作流** —— 桶过滤 + 工作项账本 + 暗房灯箱终裁，支持坏图处理；终裁结论回写检测事实，形成数据闭环。
- **模型发布流水线** —— 模型库勾选（支持多选批量、逐条独立）→ 生成带校验摘要的模型产物与单层镜像 → 直推镜像仓库；摘要以仓库回执为准，同内容可复现，仓库不回执即判失败。
- **发布记录管理** —— 已上传模型支持下线、软删与恢复；软删只清中心侧记录，仓库镜像保留，产线仍可正常拉取。

### 平台 B · 推理与检测（产线侧）

- **自包含部署** —— 无用户体系，数据落本地磁盘，适合产线工控机独立运行。
- **工位与模板配置** —— 图形化配置工位与检测模板，适配不同产线布局。
- **产线推理** —— 拉取已发布模型后本地推理，输出三档判定结果。
- **检测记录与统计** —— 检测记录留存、错图统计与日报生成。
- **错图回传** —— 可疑图与坏图经可靠队列（失败自动重试）回传中心侧，供复审与再训练。

### 设计特性

- **职责隔离** —— 两平台不共享数据库、对象存储与中间件，模型只经镜像仓库传递；中心侧从不主动连接产线侧。
- **契约先行** —— 双平台接口由契约文档冻结，双端契约测试锁定，不通过则阻断合并。
