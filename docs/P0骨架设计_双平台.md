# P0 骨架设计：双平台 monorepo（D1~D3 落实依据）

> 定位：单仓库、**两个独立可部署体**——平台 A（LS 1.x 二开，中心侧）+ 平台 B（FastAPI + 独立 React 前端，产线侧），唯一共享层为 `packages/skillname` 与 `packages/pipeline-core`。
> 依据：`docs/双平台架构与拆分方案.md`、`docs/contracts/`（D2 冻结）、`docs/MVP开发计划.md`。
> 只定义骨架（结构/职责/签名/stub 行为/验收口径），代码自 D1 起落实。归属：🟦B · 🟧C · 🟪共担 · ⬜A。

## 3. 平台 B 骨架（🟧）

### 3.1 后端目录（§1 已列），关键约定

- **单进程**：Uvicorn 1 worker；推理用进程内线程池（`INSPECT_CONCURRENCY=2`），有界队列（`INSPECT_QUEUE_MAX=32`）满则 42900。
- **SQLite**：`PRAGMA journal_mode=WAL; synchronous=NORMAL; busy_timeout=5000`；写操作串行化（单写锁），统计聚合按分钟批量写。
- **前端托管**：`app.mount('/assets', StaticFiles(...))` + SPA fallback 到 `index.html`；开发期 Vite 代理 `/api` 到 `:8990`。
- **无 RBAC / 无用户认证**：B 不做登录与用户体系；`deps.py` 仅在 `/api/v1/ingest/*` 校验平台间机器密钥 `X-Platform-Token`（非用户认证），其余接口直接放行。

### 3.2 B 侧数据表（SQLite，`b_` 前缀；见平台 B 契约 §2）

`b_model` / `b_plan` / `b_station` / `b_defect_class` / `b_inspection` / `b_bad_image` / `b_outbox` / `b_stats_daily` / `b_report` / `b_setting` / `b_audit`。

### 4.2 `packages/pipeline-core`（🟧 主笔）

```
pipeline-core/
├── pyproject.toml            # numpy + pillow；[yaml] extra: pyyaml
└── pipeline_core/
    ├── types.py              # DetectBox / DetectResult / ObjectSpec / PipelineConfig / PlanConfig / Tile / RawBox

```

签名（与架构文档 §5.2、平台 B 契约 §4 一致）：

```python
@dataclass(frozen=True)
class DetectBox:   xyxy: tuple[float, float, float, float]; class_id: int; object_code: str; score: float; model_ref: str = ""
@dataclass
class DetectResult: boxes: list[DetectBox]; tiling_meta: dict; verdict: str; verdict_reasons: list[str]
@dataclass
class ObjectSpec:   code: str; model_ref: str; class_map: dict[int, str]; recheck_min: float; auto_min: float; risk_level: int
@dataclass
class PipelineConfig: objects: list[ObjectSpec]; tile_size: int = 1280; overlap: float = 0.2
@dataclass
class StationSpec:  code: str; plan: str; enabled: bool
@dataclass
class PlanConfig:   plan_id: str; version: int; objects: list[ObjectSpec]; stations: dict[str, StationSpec]

class RuntimeModel(ABC):    def infer(self, tiles: list[np.ndarray]) -> list[list[RawBox]]: ...

def slice_image(img, tile_size=1280, overlap=0.2) -> list[Tile]
def box_to_global(box, offset) -> DetectBox
def merge_across_tiles(boxes, iou_thr=0.5) -> list[DetectBox]
def decide_verdict(boxes, cfg) -> tuple[str, list[str]]
def run(image, cfg, models: Mapping[str, RuntimeModel]) -> DetectResult
def load_plan(yaml_text: str) -> PlanConfig
class StubRuntimeModel(RuntimeModel)
```

**调用方适配器**（不进公共包）：
- A：`aoi/prelabel/runtime.py::OnnxRuntimeModel`（Celery GPU worker 内）；
- B：`infer-platform/backend/app/inference/runtime.py::OnnxRuntimeModel`（FP32/FP16、CUDA/CPU）。

## 5. D1~D3 落实步骤

**仓库线（⬜A 主笔）**
- D1：monorepo 目录 + `packages/` 两包骨架 + CI 骨架（lint/test/契约测试）+ 双平台端口与网络规划。
- D2：A 侧 compose（nginx/ls-backend/workers/pg/minio/redis）+ B 侧 compose/systemd（backend/frontend 构建）+ 跨机连通性脚本 + 离线依赖清单。
- D3：契约测试挂 CI；B 前端脚手架与 mock。

**平台 A 线（🟦B 主笔）**
- D1：`label_studio/aoi/` app 骨架 + 注入点 + `aoi_training` 四表迁移 + `skillname` 枚举裁定 + `aoi/urls.py` 挂载。
- D2 上午：共享表迁移 + label config 生成 stub + aoi API 全量 stub（`/api/datasets|train|review|inspect|system` + `/api/ingest/*`）。
- D2 下午：**复用验证日**（LS 8 项实测，输出复用结论表；不符项当场定降级方案并回写契约）。
- D3：JWT 登录链确认 + `/api/ingest/findings` 打桩应答 + `model_dispatch` 表 + 下发服务 stub + `/api/ingest/heartbeat`。

**平台 B 线（🟧C 主笔）**
- D1：FastAPI + SQLite + APScheduler + 信封/错误码 + `deps.py` + `pipeline-core` 真逻辑（切片/合并/判定/load_plan）+ `StubRuntimeModel`。

- D3：`X-Platform-Token` 校验 + 与 A 打桩联调（模型下发/方案下发/错图回传/心跳）+ B 前端对接 mock。
